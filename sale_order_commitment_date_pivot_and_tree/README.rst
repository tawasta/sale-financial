====================================================
Sale Order - Commitment date on pivot and tree views
====================================================

* Adds Commitment date (=Sale Order's Delivery Date field) to Sales Reporting pivot view and
  Order Lines treeview

Configuration
=============
* None needed

Usage
=====
* Go to Sales -> Reporting -> Sales for the pivot
* Go to Sales -> Orders -> Order Lines for the treeview
