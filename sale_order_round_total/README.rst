=======================
Sale Order: Round Total
=======================

Currency setting for rounding SO totals to a whole number

Configuration
=============
* Go to currencies, and enable rounding for any currency
* Create a product for the rounding lines

Usage
=====
* Create and confirm a SO. A rounding line appears automatically
